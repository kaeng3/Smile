# 빅웨이브로보틱스 기본적 분석

작성일: 2026-10-20 · 원본: [Claude 문서](https://claude.ai/code/artifact/7c0e69c0-4eb0-4307-b044-111e9565c918)

빅웨이브로보틱스(0035S0)는 로봇 자동화 플랫폼 '마로솔'과 통합관제 '솔링크'를 운영하는 회사입니다. 2026년 9월 29일 기술특례(사업모델)로 코스닥에 상장했고, 공모가는 밴드 상단인 18,000원이었습니다. 다만 2026년 상반기 매출의 89%가 로봇 상품 판매이고, 상반기 영업손실은 8.6억원입니다. 연간 추정 매출 358.6억원의 72%를 하반기에 채워야 해서, 추정 실적 달성 여부가 핵심입니다.

근거 자료는 2026년 9월 14일 제출된 증권신고서(정정, 2026.6.30 반기 기준)입니다. 투자 권유가 아닌 학습용 정리입니다.

## 1. 어떤 회사인가

2020년 9월 설립한 로봇 자동화 중개·구축 회사입니다. 고객이 마로솔에 문의하면 로봇을 골라 공급하고, 설치는 외부 SI 파트너(OSI)에 맡깁니다. 2025년 11월 미국 법인을 세워 2026년부터 연결 재무제표를 씁니다.

| 항목 | 내용 |
| --- | --- |
| 최대주주 | 김민교 대표, 공모 후 46.66% (특수관계인 포함 56.77%) |
| 상장 | 2026.9.29 코스닥, 기술성장기업(사업모델 평가 AA·A) |
| 주관사 | 유진투자증권(대표), 미래에셋증권(공동) |
| 직원 | 63명 (신고서 제출일 기준) |
| 연구개발비 | 상반기 4.9억원, 매출의 4.9% (전액 판관비 처리) |
| 신용등급 | B0 (나이스디앤비, 2026.2) |

| 사업 | 내용 |
| --- | --- |
| 상품 매출 | 청소·서비스 로봇(상업), 협동로봇·AMR(제조) 공급. 가우시움 청소로봇 비중이 큼 |
| 시스템구축 | 공장·물류 자동화 턴키 구축. 고객 검수가 끝나야 매출 인식 |
| 서비스 | 솔링크 구독, 유지보수, 용역 |

특수관계자 매출, 대주주 거래, 채무보증, 소송(피고)은 모두 "해당 없음"입니다.

## 2. 제품별 매출

2026년 상반기 매출은 99.8억원입니다. 상품 판매가 89%이고, 플랫폼 성격의 서비스 매출은 3.9%에 그칩니다.

| 구분 (억원) | 2024 | 2025 | 2026 상반기 | 비중 |
| --- | --- | --- | --- | --- |
| 상품-상업(서비스로봇) | 41.6 | 70.9 | 26.8 | 26.8% |
| 상품-제조로봇 | 42.7 | 67.6 | 35.0 | 35.1% |
| 상품-기타 | 0.1 | 5.2 | 27.1 | 27.2% |
| 시스템구축 | 52.7 | 53.8 | 7.1 | 7.1% |
| 서비스(솔링크·용역) | 1.5 | 9.9 | 3.9 | 3.9% |
| 합계 | 138.5 | 207.4 | 99.8 | 100% |

- '상품-기타'가 상반기 27.1억원으로 급증했습니다. 세부 품목은 공개하지 않았습니다. 수입 단가가 대당 약 1억원이어서 휴머노이드 등 고가 장비로 보입니다(추정).
- 시스템구축은 연말 검수에 몰립니다. 상반기 7.1억원은 작년 연간의 13%입니다.
- 2025년 최대 고객 한 곳이 매출의 13.3%(27.7억원)였는데, 올해 상반기에는 0.1%입니다. 고객이 해마다 바뀌는 구조입니다.
- 신고서 제출일 수주잔고는 93.9억원입니다(그린필드 32억, 일반 50.3억, 휴머노이드 11.5억).

## 3. 연결 실적

매출은 늘었지만 판관비가 41% 늘면서 상반기 영업적자로 돌아섰습니다. 7~8월 잠정 매출도 월 3억원 수준입니다.

| 항목 (억원) | 25년 상반기 | 26년 상반기 | 26년 1분기 | 26년 2분기 | 26년 7~8월(잠정) |
| --- | --- | --- | --- | --- | --- |
| 매출 | 93.6 | 99.8 (+6.6%) | 30.2 | 69.6 | 5.8 |
| 매출총이익률 | 27.9% | 24.6% | - | - | - |
| 판관비 | 23.5 | 33.2 (+41%) | - | - | - |
| 영업이익 | 2.7 | -8.6 | 미기재 | 미기재 | -4.3 |
| 순이익 | 3.2 | -8.6 | - | - | - |

- 연간으로는 2024년 138.5억원에서 2025년 207.4억원(+49.8%)으로 늘었고, 영업이익 6.7억원으로 첫 흑자를 냈습니다.
- 2024년 순손실 58.6억원은 상환전환우선주(RCPS) 평가손실 때문입니다. 2024년 11월 전량 보통주로 바뀌어 이 왜곡은 사라졌습니다.
- 매출총이익률 24~28%는 유통업에 가까운 수준입니다. '플랫폼'이라는 표현과 달리 하드웨어 마진 구조입니다.
- 회사는 "2026년 2분기 LTM 영업·순이익 흑자"라고 적었습니다. 그러나 신고서 손익계산서로 계산하면 LTM 영업손실 4.5억원, 순손실 3.7억원입니다.
- 2025년 상반기 매출이 표마다 다릅니다(손익계산서 93.6억원, 반기별 표 90.2억원). 2025년 반기는 검토받지 않은 수치입니다.

## 4. 재무 건전성

차입금이 없고 공모로 272억원이 들어와 재무 부담은 작습니다. 다만 매출채권 회수 기간이 깁니다.

| 지표 | 값 | 의미 |

- 반기 검토 감사인이 삼일회계법인에서 이정회계법인으로 바뀌었습니다. 의견은 모두 적정·검토입니다.

## 6. 밸류에이션

주관사는 실적 기준 PSR로 공모가를 정했습니다. 미래 이익을 할인한 PER 방식은 참고로만 냈는데, 그 값은 공모가보다 30% 낮습니다.

| 산정 항목 | 값 |
| --- | --- |
| 방식 | 2026년 2분기 LTM 매출 213.7억원 × 비교기업 평균 PSR |
| 비교기업 (PSR) | 유일로보틱스 22.75배, 유진로봇 12.57배, 피앤에스로보틱스 11.68배, 휴림로봇 6.78배, 라온로보틱스 1.98배 |
| 평균 PSR | 11.15배 → 주당 22,526원 |
| 할인율 | 20.11\~33.42% → 밴드 15,000\~18,000원 |
| 참고: PER 방식 | 2028년 추정 순이익 80.5억원을 연 20%로 2.5년 할인 → 51.0억원 × PER 26.32배(라온로보틱스) = 주당 12,704원 |

- 평균 PSR은 유일로보틱스(22.75배) 한 곳이 끌어올립니다. 이를 빼면 평균 8.25배입니다.
- PER 방식의 할인율 20%는 기준일 WACC(약 39%)가 아닌 2024~2025년 평균(18.4%)을 썼습니다. 그래도 PSR 대비 43.6% 낮습니다.
- 회사 추정은 매출 2026년 358.6억, 2027년 493.4억, 2028년 655.3억원입니다. 순이익은 26.5억, 48.6억, 80.5억원입니다.
- 2026년 추정은 현실성이 낮아 보입니다. 1~8월 누적 매출은 105.6억원(추정치의 29.4%)이고, 9~12월에 253억원이 필요합니다. 작년 하반기 매출(113.9억원)의 2.2배입니다.
- 회사가 '확보'했다고 본 매출은 196.6억원(기인식 102.7억 + 수주잔고 93.9억)입니다. 나머지는 수주확률 60%를 곱한 기대치입니다.

상장 후 주가는 첫날 공모가의 3배를 넘었다가 공모가 아래까지 내려온 뒤 반등 중입니다.

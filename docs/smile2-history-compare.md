# 로컬 과거 재료 비교
과거 이브닝 JSON을 브라우저에서 직접 선택하고 종목코드, 비교 기준일, 당일 뉴스 제목을 입력한다. 동일 날짜 및 미래 날짜를 제외하고 정규화 제목 일치와 문자 3-gram/단어 Jaccard 유사도를 표시한다. 유사도 기준은 시범 검색 설정(기본 0.30, 선택 가능)으로 실제 동일 사건 판정 기준이 아니다. 자료 공백 또는 검색 미검출은 신규 재료의 증거가 아니다. 원본과 결과를 서버로 보내거나 공개하지 않는다. 장후 종목 카드에서 종목코드와 날짜만 전달한다. 뉴스 본문 및 AI 의미 분석은 별도 개발 대상이다.

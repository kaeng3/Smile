# Smile 2.0 — 개발 계약 및 검증 기준

## 현황
- 기존 main, data, archive, db-seed 및 스캐너 로직 보존. 별도 브랜치에서 작업.
- 기존 뉴스 수집: 41 RSS + 4 포털, 정규화 제목 앞 28자 중복 제거, 수집시각 기준 장 구분. 2026-11-26 22:27 KST 기준 43 성공, 2 실패, 당일 수집 1,438건.
- 이브닝 데이터: 기존 가공 JSON 85,055,886 bytes; 공개 저장소 및 종목별 Pages 배포는 비공개 저장이 아니다. 원본 재배포 금지. 접근권한·저작권 확인 및 비공개 저장소 이전/기존 공개 이력 처리 계획 별도 필요. 기존 운영을 몰래 변경하지 않는다.
- 첨부 참고 HTML: 장전 120 기사/23분류, 장후 36 기사/19묶음. 참조 UI 구조만 활용, 외부 코드 및 기사 원문 재게시 금지.

## 설계
1. 수집: 공식 공시·정책·공개 RSS, URL/발표시각/수집시각 별도 보관, 실패 지표 기록. 원문 저장은 권한에 따름.
2. 정규화: URL 정리, 원 출처와 포털 구분, 사건 후보 그룹. 사건 단계/수량 불일치 보존. 제목만으로 확정 사건이나 인과 관계를 주장하지 않는다.
3. 분석: 일반 알고리즘 우선, AI는 애매한 후보 및 핵심 사건에만 적용. 캐시/예산/재시도 상한 설정 후 도입.
4. 브리핑: 장전·장후 기간은 거래일 캘린더 및 발표시각 기준으로 확정. 발표시각 미상은 별도 표시. 기업 연결은 직접 근거/간접/추정 구분.
5. UI: 정보 우선순위, 읽기 좋은 본문, 날짜/분류 탐색, 원문 링크, 모바일, 키보드 접근. 기존 페이지로 돌아가기 유지. 가짜 시장 데이터 금지.
6. 기술 분석: KRX 정규장 실거래대금 사용, 양봉은 종가>시가, 기존 전략 수정 금지. 이일홍 연속 두 거래일, 매집박스 몸통 상단, 거감음봉 및 회복 상태. 임계치는 검증 후 확정.
7. 품질: 출처 성공률 외에 누락·중복·잘못된 묶음·잘못된 종목 연결을 수동 표본으로 평가. 기준일 비교 후 배포.

## ECC 적용
MIT 공개 저장소 affaan-m/ECC의 frontend-design-direction, cost-aware-llm-pipeline, python-testing, security-review, verification-loop 지침을 검토하여 이 문서 및 격리된 프로토타입에 반영. 외부 스크립트 실행/전체 자동 설치 없음. 실제 테스트 성공을 확인하기 전에는 통과로 표시하지 않음.

## 실행 (로컬)
- python -m smile2.audit_history stock_news_history.json (집계만 출력)
- python -m smile2.news_engine --input news_feed/news.json --output smile2/events.json
- python -m unittest discover -s tests -p test_smile2.py
- python -m http.server 8000 후 /smile2/ (운영 사이트 배포 아님)

## 미해결
전체 역사 데이터 수록 범위, 실시간 수집 검증, 기존 전략 회귀, 이일홍 수치 기준, 비공개 저장소 및 데이터 이전, 실제 AI 비용과 브리핑 운영 시각, 최종 배포 승인.

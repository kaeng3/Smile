# Gemini 무료 프로젝트 사용 계획
기존 SMILE GitHub secret을 재사용한다. Google 공식 요금표 기준 무료 표준 입력·출력이 명시된 gemini-3.5-flash-lite 고정 모델만 사용하며 다른 모델, 검색 grounding, 유료 전환 또는 재시도는 없다. 실제 프로젝트가 Free tier인지 확인 후 수동 워크플로우에서 확인 체크가 필요하다. 연결된 결제 계정이 있다면 무료 보장은 불가능하다.
신규 호출기는 자체 제한 하루 3회(미국 태평양 날짜), 최소 10분 간격, 실행당 1회로 시작한다. 이는 Google이 보장하는 한도가 아니며 기존 스캐너·외부 프로그램의 사용량은 포함하지 않는다. 프로젝트별 실제 한도는 AI Studio에서 확인. 오류 또는 미확정 예약이 있으면 당일 정지. 예약을 데이터 브랜치에 먼저 기록하여 재실행 중복을 방지한다. 최근 30일의 사건/패킷 ID만 저장한다. 신규 AI 답변은 사이트에 자동 게시하지 않는다. 수동 선택 시에만 공개 제목 근거로 만든 검토용 초안을 공개 저장소 Actions artifact로 남길 수 있다. 구독 자료·개인 자료 입력 금지. 실제 API 호출은 아직 수행하지 않았다.

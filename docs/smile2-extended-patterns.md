# 상승형 이일홍 및 고가놀이 연구 확장
인계서에 따라 수평 박스와 상승형 몸통 채널을 분리하고 오래된 몸통 저항은 표시만 한다. 상승 채널은 몸통 상·하단 선형 기울기 및 평행 경계로 근사한다. 고가놀이는 이전 고가를 넘는 갭 양봉 이후 일정한 고가 몸통 구간을 연구 후보로 정의하고 하단 지지, 이탈, 조정 음봉 이후 상단 재돌파를 구분한다. 이는 사용자가 확정한 정량 기준이나 유튜버 공식 조건이 아닌 검증용 가설이다.
기존 --rules 외에 --extensions 로 Extensions 필드를 명시한 JSON을 제공할 때만 활성화. 기본값 없음. 테스트 값은 합성 자료 검증용. 거래대금 임의 하한 없음. 기존 수평 전략 및 운영 스캐너는 확장 미사용 시 유지. 실제 로컬 정규장 자료 검증은 미실시.

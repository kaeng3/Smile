# 운영 전 검증 및 비교 기준

1. 수집량과 실제 보도 시각 확보율을 따로 기록한다. 기존 데이터에는 날짜 없는 시각이 많아 실제 발행 시각으로 소급하지 않는다.
2. 시그널리포트/이브닝 비교는 사용자가 보유한 로컬 HTML로 수행한다. `python -m smile2.benchmark --reference /private/report.html --news /local/news.json`은 외부 URL의 정확 일치와 출처별 집계만 출력한다. --host를 여러 번 지정하여 기사 도메인만 선별할 수 있다. 구독 자료를 CI에 넣지 않는다. 원문 URL 일치율은 사건 재현율이 아니다. 동일 사건의 다른 언론 보도, 과거 근거 링크, 시점 차이 및 관련 없는 링크는 별도 검토한다.
3. 거래일은 `python -m smile2.calendar --day YYYY-MM-DD`로 XKRX 캘린더에서 확인한다. exchange-calendars==4.13.2 필요. 주말만 판정하는 폴백을 허용하지 않는다. 특수 개장일에는 기존 시범 브리핑 시간 대신 실제 세션 시각을 반영해야 한다(아직 통합 전).
4. 실제 KRX 정규장 OHLCV·실거래대금과 비교하여 기술 분석 기준을 확정한다. 매매 기준을 자동 선택하지 않는다.
5. 최신 브랜치 CI 성공, 실제 브라우저·신규 수집 테스트, 저작권 및 공개 데이터 검토, 기존 운영 유지 확인 이후에만 병합을 검토한다. 현재 운영 페이지와 데이터 브랜치는 변경하지 않는다.

6. 브리핑 및 통합 미리보기의 --calendar 옵션은 XKRX 세션의 개장·폐장 및 직전 거래일을 검증한다. 미지정 시 시범용 정규 시각이며, 데이터에는 해당 근거를 표시한다. 공식 공시 발행 기업과 뉴스 제목 언급을 구분하되 양쪽 모두 수혜 또는 주가 인과관계를 확정하지 않는다.

# [특징주] 전용 보기 (사용자 요청)
명시적 [특징주] 제목 표기(전각 괄호·공백·HTML entity 정규화 포함)만 포함한다. 일반 급등/강세 기사나 본문 추론으로 자동 편입하지 않는다. 기존 수집 점수 미달이어도 새 URL은 보관하되 점수 부풀림 없음. 동일 URL 기존 보관 제목은 변경하지 않으며 수집처가 표시를 제공하지 않으면 발견하지 못할 수 있다. 기존 장전/장후 시각 검증을 그대로 적용한다. 발표시각 확인은 발표 최신순, 미상은 수집 최신순. 일반 산업별 분류는 유지하고 전용 보기로 교차 조회하므로 합산 금지. 원문 링크·종목 언급·산업 근거를 보존하며 실제 가격 인과를 단정하지 않는다. 유료 자료, 본문, API 사용 없음.

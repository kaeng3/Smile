# 로컬 전략 검증
기준일 종가까지의 자료만 검색 함수에 전달한다. 다음 거래일 시가에서 진입한 것으로 가정하고 지정 거래일 종가의 수익률을 계산한다. 연구 종료일 이후 자료는 성과 계산에 사용하지 않는다. 동일 종목/전략/첫 봉/상태의 최초 발생만 집계한다. 기간별 관측 수, 미완결 수, 평균·중앙값, 양수 비율을 출력한다. 거래일과 거래대금 범위를 검사하며 원본은 전송하지 않는다.
명시적으로 정한 rules.json, 기간, horizons가 필요하며 확정 기본 매매 조건은 없다. 예: python -m smile2.pattern_backtest --input-dir D:/local/krx-regular-daily --rules D:/local/rules.json --start 2025-01-02 --end 2026-11-26 --horizons 1 3 5 10 --output D:/local/research.json
비용, 체결 가능성, 기업행위 조정, 생존편향, 비교지수, 중복 포지션은 미반영. 동일 종목의 중첩 사건은 독립 표본이 아니다. 실종목 검증 및 별도 검증 기간 전에는 전략 수익성으로 해석하지 않는다. CI에서는 합성 자료만 사용한다.

### 비용과 검증 기간
--costs JSON은 buy_bps, sell_bps, buy_slippage_bps, sell_slippage_bps를 모두 명시한다 (1bp=0.01%). 실제 세율/수수료는 사용자 확인 대상이며 임의 기본값 없음. 매수 수수료·슬리피지와 매도 비용을 반영한 추정 순수익률을 총수익률과 분리한다. --validation-start YYYY-MM-DD로 개발/검증 구간을 나누며 개발 구간 신호의 결과가 검증 구간에 걸치면 제외한다. 두 구간 동일 규칙을 사용하고 자동 최적화하지 않는다. 검증 구간을 보고 규칙을 변경하면 새로운 독립 검증 기간이 필요하다. 실거래 체결·세율·기업행위는 여전히 미검증.

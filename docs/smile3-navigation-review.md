# 메뉴 정리 검수
상단 5개 메뉴만 유지: 장전, 장후, 테마 연구, 기술적 분석, 기존 스캐너. 특징주와 지연 뉴스는 PC/모바일 목차 아래로 이동. 뉴스 검색 페이지는 공개 메뉴에서 제거하되 수집 품질/발표 시각 미확보 및 기존 사건 딥링크 용도로 유지. 장전/장후 검색창 그대로. 과거 재료는 기술적 분석 종목 상세에 통합: 기존 공개 최근 events.json 자동 조회(발표일/관측일 모두 기준일 이전, 종목 코드 직접 언급), 장기 이력은 보유 로컬 JSON을 페이지당 한 번 선택하여 연결. 서버 전송/영구 저장/공개 아카이브 복사 없음. 별도 history.html 주소는 호환용으로 유지. 기술적 분석 후보 자체는 아직 로컬 candidates.json 입력 방식. 과거 자료 누락은 신규 재료의 증거가 아니다.

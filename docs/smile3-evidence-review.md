# 근거 수준 및 검토 우선순위
ECC research-ops/deep-research 원칙을 적용한다. 뉴스 수/언론사 수는 독립 검증을 의미하지 않는다. 공식 자료 연결은 기존 설정의 source_kind/source_feed 및 HTTPS 호스트가 일치하는 경우와 DART 정확한 공시 링크 형식으로 제한하며 본문/사실을 검증한 것이 아니다. 원문형/포털/검색 경유 링크를 각각 집계한다. 기사 본문은 아직 수집하지 않는다. 정정/부인/취소/위험/복합 단계는 검토 우선 단서이며 실제 악재나 가격 방향을 확정하지 않는다. 산업별 전체 사건을 유지하고 B안에 선택적 검토 필터를 제공한다. 특징주에도 동일 근거를 표시한다. 기본 산업순/기사순은 그대로 두며 임의 중요도 점수는 도입하지 않는다. 공식 자료 연결은 현재 등록 출처만 감지할 수 있다. 실제 독립 출처·본문·신규성·수급 확인과 의미 정확도 평가는 후속 검증 대상이다.

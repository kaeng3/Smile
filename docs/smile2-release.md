# 첫 운영 배포 범위
기존 Pages 공통 빌더 data_store.py site에서 생성된 공개 뉴스 메타데이터만 이용하여 /smile2/ 정적 화면을 생성한다. 기존 스캐너 로직 및 배포 데이터는 유지하고 루트 헤더에 링크를 추가한다. XKRX 거래일을 검증하지 못하거나 데이터 생성 실패 시 기존 홈페이지를 유지하고 신규 경로에 오류 안내를 표시한다. 신규 구독 자료나 주가 원본을 게시하지 않는다. 기존 공개 이브닝 데이터의 이전 및 기존 이력 제거는 별도 작업이다. 공식·추가 언론사 시험은 운영 연결/이용조건 검토 전에는 별도 시험에만 포함한다. AI API 및 검증되지 않은 매매 조건은 사용하지 않는다.

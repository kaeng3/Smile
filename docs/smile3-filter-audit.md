# 수집 점수 필터 감사
ECC eval-harness/data-scraper-agent의 수집과 평가 분리 원칙을 적용한다. 격리 시험 수집에서 --audit-filter --output-dir ... --no-brief를 사용하면 유효 URL의 점수 기준 탈락 자료(제목, 링크, 출처, 관측 시각, 기존 점수와 필터 사유, 종목·키워드 단서)만 별도 파일에 보존한다. URL 중복과 이후 동일 수집에서 보관된 URL을 제외한다. 최대 20,000개, URL 해시 순으로 최대 150개 검토 표본. 선택된 표본은 아직 사람이 라벨하지 않았고 확률적 대표성은 검증하지 않았다. 전체 원천 기사 수나 필터 재현율로 해석 금지. 기존 운영 수집 필터는 이번 변경으로 완화하지 않는다. CI artifact 7일 보관, Pages/data branch에 추가하지 않음. 공개 메타데이터만 포함하며 본문·비밀값·유료 자료 제외. 이전에 이미 누락된 기사는 소급 복구되지 않는다. 독립 relevance 라벨 검수 후 재료별 누락 패턴을 조사하고 기존 기준과 새 기준을 동일 입력에서 비교할 계획이다.

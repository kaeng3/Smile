# 재료 단계 검토
ECC research-ops의 근거/추론 분리와 regex-vs-llm의 명시적 단서 추출을 적용한다. 산업 대표 분류와 별도로 제목에서 설/부인/취소/검토/신청/잠정/계약/승인/완료/임상/위험 단서를 추출하며 원문 URL과 일치 단어를 기록한다. 승인 신청은 승인 확정으로 처리하지 않는다. 복합 단서는 모두 표시하고 검토 대상으로 지정한다. 제목의 부정, 인용, 과거 시제 등은 본문 검토 전 확정 불가. 재료 호악재·매매 우선순위 점수 자동 산출 금지. 산업별/특징주 화면에 동일 근거를 표시한다.
CI에서 실제 Pages events.json과 150개 blind 검수 후보를 별도 artifact로 보관한다. 실행마다 데이터가 달라질 수 있으므로 하나의 artifact를 고정한 후 사람 라벨을 작성한다. 과거 개발 표본과 겹치는 항목은 독립 평가에서 제외하고 별도 기록한다. 아직 독립 정답 및 품질 통과 기준 없음.

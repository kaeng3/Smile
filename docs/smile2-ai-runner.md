# 로컬 AI 분석 호출기
기존 제목 근거 패킷을 실제 Gemini REST 요청으로 보낼 수 있는 선택적 CLI. 자동 CI 및 Pages에는 연결하지 않는다. 공개 제목/URL만 입력하며 구독 자료와 개인 자료는 제외한다. GEMINI_API_KEY 환경변수, 명시 모델 ID, 최신 모델별 입력·출력 USD/백만토큰 가격, 회차 예산, --execute 옵션을 요구한다. 가격은 https://ai.google.dev/gemini-api/docs/pricing 에서 검증한다. countTokens 및 최대 출력 토큰으로 생성 전 예상액을 계산한다. 오류·예산 초과 예상 시 중단하고 재시도하지 않는다. 실제 provider 과금 상한을 보장하지 않으므로 별도 프로젝트 쿼터·결제 한도 설정 필요. 모델마다 추론 토큰 제한 동작이 다를 수 있음. 본문·공급망 검증이나 AI 답변 자동 게시 없음. 실제 API 테스트는 미실시. 단위 테스트에서는 모의 응답만 사용한다.

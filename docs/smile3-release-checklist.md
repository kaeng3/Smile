# SMILE 3.0 통합 검증판
B안 기본 진입은 기존 루트 헤더의 뉴스 연구실 링크에서 editorial.html로 연결한다. 기존 smile2/index.html 뉴스 탐색과 스캐너는 그대로 유지. 매 거래일 정규장 종료 이후 장후, 그 이전 장전을 기본 진입으로 사용한다. 휴장일은 직전 거래일. 미완성 데이터는 검증판 및 부분 리포트로 표시. 마감 이후 보충 목록은 해당 회차 늦은 기사·발표 시각 보강·특징주 표시 보강을 별도 조회하며 미래 관측값 제외. 과거 회차에 소급하지 않는다. 다음 회차와 중복 가능. 아직 영구 보관 아카이브가 아님.
배포 전: 최신 PR CI 세 작업 성공, 실제 Pages 빌드, 모바일/검색/필터/특징주/보충 목록 테스트, 기존 루트 링크와 fallback 검증.
배포 후 검토할 사항: 실제 분류 독립 정답 라벨링, 탈락 감사 기사 검수, 출처 장애 및 수집 기간 이력, 본문 접근 권한 및 교차 검증, Gemini 무료 수동 실행 검증, 장후 거래대금 실제값, 과거 재료 비교 정확도, 영구 리포트 보관, 백테스트 PR7 보류. 뉴스 단서 검증판이지 검증된 매수 신호 또는 완전한 수집을 보장하지 않는다.

# SMILE 3.0 전환
사용자 요청: 기존 SMILE 2.0 뉴스 연구실 완전 대체. 생성된 /smile2/ 및 index.html, brief.html은 B안 editorial.html과 동일 화면을 제공한다. 기존 장전·장후 쿼리와 index.html?event= 및 #sources는 보존(사건 및 수집 품질 링크는 search.html로 이동). 기존 검색 기능은 search.html, 테마·차트·로컬 과거 자료는 유지하며 아이보리 색상과 3.0 메뉴로 통일한다. 기존 brief JSON 및 데이터는 호환성을 위해 유지하되 50개 제한 화면은 기본 UI에서 제거한다. 추가 언론사 시험 자료는 전체 뉴스 검색의 수집 구분 필터로 조회 가능. 루트 스캐너와 기존 데이터는 보존. 원본 index.html/brief.html 소스는 되돌리기 참고용이며 생성 사이트에서는 B안으로 덮어쓴다. 최신 CI 모두 통과 후 병합. 제목 기반 분류 정확도 및 본문 검증은 아직 미완료이며 3.0 검증판으로 표시한다.

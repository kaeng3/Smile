# 뉴스 수집 품질 기준
매매 연구에 사용하는 뉴스의 정확성과 누락 방지가 최우선이다. 2026-11-27 격리 시험 run 45982086611에서 한국경제 증권/경제/IT, 한경 마켓인사이트 HTTPError, 동아 경제 URLError로 40/45 성공. HTTP 상태 코드 미기록이므로 원인 확정 불가. 새 수집기는 500/502/503/504(재시도 지시 없는 경우)와 타임아웃만 1회 재시도; 403/429 우회 금지. RSS 처리 상한 40→200, 응답 8MiB 상한, 상한 가능성 표시. 실제 공급자가 제공한 범위 밖 기사까지 수집된다는 의미는 아니다. 최신 수집 상태·시각·출처별 오류·점수 미보관 URL 수를 B안에서 확인한다. 90분 갱신 지연 표시 기준은 30분 스케줄을 고려한 임시 운영 기준이며 전체 회차 coverage가 아니다. 향후 시간별 수집 이력·독립 원천 대조·본문 확인·의미 분류 독립 검수·사건 단계 구별·상승 원인과 추정 분리 검증 필요. 이용 제한 회피 및 비용 자동 전환 금지.

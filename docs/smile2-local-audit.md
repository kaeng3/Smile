# 실종목 데이터 준비 상태 점검
로컬 DAUM_KRX_REGULAR 자료의 구조, 요청 기준일, 최근 필요한 봉 수, 거래량·거래대금 양수 여부, OHLC/거래량 범위 및 거래일 누락을 검사한다. 데이터를 변경하거나 서버에 보내지 않는다. 출력은 종목코드 없는 집계만 제공한다.
예: python -m smile2.local_audit --input-dir "D:\local\krx-regular-daily" --as-of 2026-11-26 --min-bars 60
60은 실행 예시이며 확정 전략 기준이 아니다. 최근 창 통과는 전체 역사 또는 매매 전략 통과와 다르다. --without-calendar는 형식 검사 전용이다. 출처 표식만으로 정규장 거래 범위를 독립적으로 확인할 수 없다. 실제 사용자 PC 실행은 아직 하지 않았다.
